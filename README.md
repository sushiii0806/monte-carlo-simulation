#  Monte Carlo Simulation

## Overview

Developed a Monte Carlo Simulation model in Python to forecast potential stock price movements under uncertainty. The project uses random sampling and probability distributions to generate thousands of possible future price paths, helping analyze risk, volatility, and market behavior under different scenarios.

## Features

- Stock price simulation
- Random path generation
- Risk analysis
- Volatility modeling
- Future price forecasting
- Data visualization

## Key Concepts Covered

- Probability Theory
- Random Variables
- Monte Carlo Simulation
- Stock Price Forecasting
- Volatility Analysis
- Risk Modeling
- Statistical Simulation
- Financial Data Analysis


## Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- yfinance

## Learning Outcome

Gained practical experience in using probabilistic methods to model uncertainty in financial markets and understand how quantitative analysts simulate future asset price movements for risk assessment and decision-making.
